# 哈希题复盘

> 对于哈希表，我的体会就是：这个数据结构非常适合存放已经出现过的数据，并便于直接去查找。同时哈希表还有优秀的去重性，非常适合存放数据和统计数据。

### 1. 两数之和

力扣的开始。一开始是真不会，但后面是刷的次数最多的题目。

思路就是：建立一个哈希表，存储找过的数据。要找的目标是target - nums[i]，如果这个目标在哈希表里(这个数存在)，那么就找到了，return这个vector。

```cpp
// 两数之和
#include <iostream>
#include <vector>
#include <unordered_map>

std::vector<int> twoSum(std::vector<int>& nums, int target){
    // 初始化一个哈希表
    std::unordered_map<int,int> visited_num;
    // 遍历nums
    for(int i = 0; i< nums.size(); i++){
        int find_target = target - nums[i];
        auto it = visited_num.find(find_target);
        if(it!= visited_num.end()){
            // 找到
            return std::vector<int>{i,it->second}; 
        }
        else{
            // 未找到
            visited_num.insert({nums[i],i});
        }
    }
    return std::vector<int>{};

}
```

### 2. 字母异位词分组

这道题我的习惯是：对于每个词，我要先将其排序，同时额外用一个变量存储原词。将排序后的词与哈希中的词进行对比，如果没出现过，那就存入哈希，哈希的second对应的是这个词应该出现在ans中的位置（这个位置正好是ans.size(),推出来的）。如果出现过，那就直接存到对应的位置vector里。这个题很难用语言描述，代码比较清晰。

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
#include <algorithm>
// input : vector<int>& strs:['eat' 'tea' 'bat']
// output: vector<vector<int>> [['eat','tea'],['bat']]
using namespace std;

vector<vector<string>> groupAnagrams(vector<string> &strs){
    //初始化
    vector<vector<string>> ans = {};//初始化一个ans
    unordered_map<string,int> visited_word;//哈希表：记录表中经过排序后的词，以及其对应的在ans中的位置

    //循环
    for(int i = 0; i < strs.size(); i++){
        // 先保留原词
        string initial_word = strs[i];
        // 对当前词排序
        sort(strs[i].begin(), strs[i].end());
        // 查找排序后的词aet,abt在哈希中是否存在
        auto it = visited_word.find(strs[i]);
        if(it == visited_word.end()){
            // 不存在，添加到哈希中，并记录目前其加入ans的位置,如果是不同字母组成的，位置正好是对应的ans.size()
            // 如eat加入到ans[0],加入后size变为1,后续bat再加入时，正好加入ans[1]位置
            int location = ans.size();
            visited_word.insert({strs[i],location});
            // 加入到ans中
            ans.push_back(vector<string>{initial_word});
        }
        else{
            // 如果找到了
            ans[it->second].push_back(initial_word);
        }
    }
    return ans;

}
```

### 3. 最长连续序列

这道题有很多小细节，大体的思路是：

- 先将所有数字排序存入哈希表(unordered_set)，这样可以去重，便于高效搜索

- 遍历哈希表，找找不到num -1的元素，这种元素可以作为序列头。

- 找到一个序列头后，循环寻找其下一元素存不存在，并更新max_length

当时做的时候，是想着遍历vector，但是不够高效，遍历哈希表最高效，且哈希表自带去重属性。

```cpp
#include <iostream>
#include <vector>
#include <unordered_set>
#include <algorithm>
using namespace std;


// 输入：[100,4,200,1,3,2]
// 输出：4

int longestConsecutive(vector<int> &nums){
    //initialize
    int max_length = 0;
    unordered_set<int> all_nums(nums.begin(),nums.end());// 这样直接将nums排序后放进哈希，还能去重

    // 这里一个细节：遍历哈希表效率更高。哈希可以自动去重，且不用排序。
    for(int num : all_nums){
        int first_find = num - 1;
        auto it = all_nums.find(first_find);
        if(it == all_nums.end()){
            // 目标：就是要找找不到num-1的元素
            // 找不到num-1，说明是一段的头，接下来去循环找num+1
            int cur_num = num;
            int length = 1;
            while(all_nums.find(cur_num + 1) != all_nums.end()){
                length++;
                cur_num++;
            }
            max_length = max(length, max_length);
            
    }
        else{
            continue;
        }
    }
    return max_length;
}
```
