### 题目：无人机编队日志分析

你正在开发一个无人机编队系统。系统会产生一串飞行日志，每条日志包含：

```
无人机ID  执行状态
```

其中无人机 ID 是字符串，例如 `UAV01`、`UAV02`，状态可能为：

```
SEARCH
MOVE
RETURN
LAND
```

现在给定一段日志，请完成以下统计：

1. 统计**每架无人机出现的次数**。
2. 找出**出现次数最多的无人机**。
3. 统计每种状态出现的次数。
4. 找出**执行过 `RETURN` 状态的所有无人机**，并按照无人机 ID 的字典序输出。

例如输入：

```
10
UAV01 SEARCH
UAV02 MOVE
UAV01 MOVE
UAV03 SEARCH
UAV02 RETURN
UAV01 SEARCH
UAV03 RETURN
UAV02 MOVE
UAV01 RETURN
UAV03 SEARCH
```

输出：

```
UAV01 4
UAV02 3
UAV03 3

Most Active: UAV01

SEARCH 4
MOVE 3
RETURN 2

Return UAVs:
UAV01 UAV02 UAV03---
```

### 建议你自己实现的函数

不要把所有代码都写在 `main()` 里面，可以尝试设计成：

```
unordered_map<string, int> countUAV(...);

unordered_map<string, int> countStatus(...);

string findMostActive(...);

vector<string> findReturnUAV(...);
```

这样可以顺便复习 C++ 的**函数参数、返回值、引用传递**。
