# 链表题目复盘

链表题目感觉之前都没太接触过，但是是挺有意思的一个数据结构，这里复盘一下。

首先是链表的基础写法，用一个结构体来写ListNode,包含其本身的value和指向下一个链表的指针next。

```cpp
struct ListNode{
    int val;
    ListNode* next;
    ListNode(int x): val(x), next(nullptr){};
};
```

### 1. 相交链表(easy)

- 思路：什么情况可以判断两个链表有相交？-> 两个链表都走A和B两个链表的路程，如果有两个链表节点地址相等的时候，那么他们就是相交。

- 输入：ListNode* headA, ListNode* headB; 输出：ListNode* 指向相交节点

- 实际操作：取两个指针pA,pB，指向headA和headB。然后循环，直到pA = pB，如果相等的时候，就是相交的节点

```cpp
ListNode* getIntersectionNode(ListNode* headA, ListNode* headB){
    ListNode* pA = headA;
    ListNode* pB = headB;
    while(pA != pB){
        if(pA != nullptr){
            pA = pA -> next;
        }
        else{
            pA = headB;
        }
        if(pB != nullptr){
            pB = pB -> next;
        }
        else{
            pB = headA;
        }
    }
    return pA;
}
```

### 2. 反转链表(easy)

- 思路：对于每个节点来说，反转链表的过程都是：让其上一个节点prev成为自己next节点，然后再更新prev和cur。

- 这里很难说明白，直接由代码说明

```cpp
ListNode* reverseList(ListNode* head){
    ListNode* cur = head;
    ListNode* prev = nullptr; 
    while(cur != nullptr){
        // 先把此节点原本的next存储起来
        ListNode* p_next = cur->next;

        // 进行链表翻转
        cur -> next = prev;

        // 更新后，更新prev和cur
        prev = cur;
        cur = p_next;
    }
    return prev; // 最后一轮循环时，cur更新为了nullptr，所以要返回prev
}
```

### 3. 回文链表(easy)

- 思路：通过快慢指针找到链表的中点，然后把后半段链表翻转。翻转后如果前半段链表和翻转后的链表相等，那么就为回文链表。

- 但是这个easy题相对复杂一点

- 整体思路：找到中点后翻转，注意奇数和偶数个情况不同的情况。奇数个时，最中间的不用翻转。

```cpp
bool isPalindrome(ListNode* head){
    // 先快慢指针找到中点
    ListNode* fast = head;
    ListNode* slow = head;
    while(fast != nullptr && fast -> next != nullptr){
        slow = slow -> next;
        fast = fast -> next -> next;
    }
    // 偶数个和奇数个情况不同，fast停的元素不一样，slow在的位置也不一样
    if(fast != nullptr){
        // 对应奇数个情况，此时fast指向的是最后一个元素
        slow = slow -> next;
    }
    // 翻转
    ListNode* reverse_head = reverseList(slow);
    
    // 验证
    ListNode* pA = head;
    ListNode* pB = reverse_head;
    while(pB != nullptr){
        if(pA -> val != pB -> val){
            return false;
        }
        pA = pA -> next;
        pB = pB -> next;
    }
    return true;
}
```

### 4. 环形链表(easy)

- 思路：依然是快慢指针，如果有环，那么快慢指针一定会相遇; 如果没环，那么fast就直接等于nullptr了

- 注意：要先更新slow和fast，要不然针对短节点，就会直接判断head = head

```cpp
bool hasCycle(ListNode* head){
    // 有环意味着没有链表的next指向nullptr
    // 所以用快慢指针：如果有环，快慢指针一定会相遇。没环就直接到nullptr了
    ListNode * slow = head;
    ListNode * fast = head;
    while(fast != nullptr && fast->next != nullptr){
        slow = slow->next;
        fast = fast->next->next;
        if(fast == slow){
            return true;
        }
    }
    return false;
}
```
