# 力扣Hot100 矩阵复盘

> hot100的四道矩阵题，我觉得更偏向机制，每道题的机制都有所不同，里面也都有一些小细节，在这里再复盘一下

### 1.  矩阵置0

这道题的核心机制在于：利用第一行和第一列的元素作为标识。

- 先排除掉第一行和第一列有0的情况，如果有，给一个flag。后面再把第一行/第一列有0的情况处理掉就好

- 遍历矩阵除了第一行和第一列的内部元素，去找内部的0, 找到后，将其对应的行和列所在的第一行/列元素置0。

- 有了标记，去给这些行/列的元素改为0

- 最后再单独处理第一行/第一列有0的情况

```cpp
void setZeroes(vector<vector<int>> & matrix){
    int m = matrix.size();
    int n = matrix[0].size();
    bool first_row_have_zero = false;
    bool first_col_have_zero = false;
    // 先判断第一行和第一列有没有0
    for(int i = 0; i < n; i++){
        if(matrix[0][i] == 0){
            first_row_have_zero = true;
            break;
        }
    }
    for(int j = 0; j < m; j++){
        if(matrix[j][0] == 0){
            first_col_have_zero = true;
            break;
        }
    }

    // 遍历矩阵内部，找0,如果找到，利用第一行和第一列元素作标记
    for(int i = 1; i < m; i++){
        for(int j = 1; j < n; j++){
            if(matrix[i][j] == 0){
                matrix[0][j] = 0;
                matrix[i][0] = 0;
            }
        }
    }

    // 根据标记，将此行/列都变为0
    for(int i = 1; i < m; i++){
        for(int j = 1; j < n; j++){
            if(matrix[0][j] == 0 || matrix[i][0] == 0){
                matrix[i][j] = 0;
            }
        }
    }

    // 如果第一行/第一列有0,把所在的这一行/列变0
    if(first_row_have_zero){
        // 第一行有0,把这一行都变成0,列在主流程里处理过
        for(int i = 0; i < n; i++){
            matrix[0][i] = 0;
        }
    }
    if(first_col_have_zero){
        // 第一行有0,把这一行都变成0,行在主流程里处理过
        for(int j = 0; j < m; j++){
            matrix[j][0] = 0;
        }
    }
}
```

### 2. 螺旋矩阵

这个题的思路是找四个边角，定义四个边角变量，然后分别从左上到右上，从右上到右下，从右下到左下，从左下到左上的顺序，依次插入vector。同时边角的范围不断缩小，循环往复。

但是最后要注意一个细节，有可能这个边界会出现不能走的情况。所以从右下到左下，从左上到右上的时候，需要加一个判断。

```cpp
vector<int> setZeroes(vector<vector<int>> & matrix){
    int m = matrix.size();
    int n = matrix[0].size();
    int top = 0;
    int left = 0;
    int right = n - 1;
    int bottom = m - 1;
    vector<int> ans = {};
    while(top <= bottom && right >=left){
        // 左上到右上
        for(int j = left; j <= right; j++){
            ans.push_back(matrix[top][j]);
        }
        top++;

        // 右上到右下
        for(int i = top; i <=  bottom; i++){
            ans.push_back(matrix[i][right]);
        }
        right--;

        // 右下到左下
        // 这里需要额外判断一下还能不能走,还有没有底边可以走,因为这个条件是大循环才判断一次的，内部需要额外判断。
        // 例子有错时发现，属于corner case了
        if(top <= bottom){
            for(int j = right; j >= left; j--){
                ans.push_back(matrix[bottom][j]);
            }
            bottom--;
        }

        // 左下到左上
        if(left <= right){
            for(int i = bottom; i >= top; i--){
                ans.push_back(matrix[i][left]);
            }
            left++;
        }
    }
    return ans;
}
```

**这两道题都比较绕，很容易有细节上的问题！**

### 3. 旋转图像

这道题的流程很简单,但是思路想不太到.

- 先把矩阵进行转置

- 然后逐行进行行内元素reverse.

```cpp
void rotate(vector<vector<int>> & matrix){
    // 思路：很巧妙，观察矩阵，对矩阵先转置再逐行反转(reverse)
    // 先转置
    int m = matrix.size();
    int n = matrix[0].size();
    for(int i = 0; i < m; i++){
        for(int j = i+1; j < n; j++){
            swap(matrix[i][j], matrix[j][i]);
        }
    }
    // 再逐行reverse
    for(int i = 0; i < m; i++){
        reverse(matrix[i].begin(), matrix[i].end());
    }
}
```

### 4. 搜索二维矩阵II

这道题的思路也很巧妙:瞄准右上角的元素.

- 因为右上角的元素在这一行内是最大的,在这一列内又是最小的,所以,如果目标比右上角元素大,那就向下移动查找(row++); 如果目标比右上角小,那就向左查找(col--).

- 一直循环比较就可以了

```cpp
bool searchMatrix(vector<vector<int>> & matrix, int target){
    // 这个题的思路很巧妙：
    // 看右上角元素，因为右上角元素一定比左边大，又一定比同列的下面几个元素小，是个非常好的判断对象
    // 如果比较target和matrix[row][col],如果target更大，那么就row++,如果target更小，那么就col--
    int m = matrix.size();
    int n = matrix[0].size();
    int row = 0;
    int col = n - 1; //把要观察的列设为最右上角的元素
    bool succ_find = false;
    while(row < m && col >= 0){
        if(target == matrix[row][col]){
            succ_find = true;
            break;
        }
        else if(target > matrix[row][col]){
            row++;
        }
        else{
            col--;
        }
    }
    return succ_find;
```
